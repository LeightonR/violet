Violet 0.1.1 installs a local Windows desktop dictation application.

This package is unsigned. Verify the published SHA-256 values before installing
it. The installer does not include speech models, does not copy an existing
model cache, and does not start a model download. Violet asks before any model
download and verifies a fixed, audited model snapshot locally before use.

Violet supports 64-bit Windows 10 version 1809 or later and Windows 11. It is
not a Windows 7, 8, or 8.1 package.

The installer places Violet under your Local AppData directory. Its optional
sign-in shortcut runs Violet in the background; the desktop shortcut opens the
compact control panel. Uninstalling Violet leaves your per-user settings and
downloaded local model cache in place.
